# Twitter

A private Flutter social timeline inspired by TwiNote and X.

## Foundation
- Home timeline with demo fan/news accounts
- Like, repost, reply and compose interactions
- Explore, notifications, messages and profile navigation
- Light, dark and system themes
- Accent palette with locally persisted preference

## Next
- Editable bot accounts and scheduled publishing
- ILLIT and NewJeans/NJZ media library
- Photo and video attachments
- Persistent posts, profiles and settings
- Configurable news integrations

## Run
```bash
flutter pub get
flutter run
```

Demo posts are placeholders, not live news. Automated news ingestion and scheduled publishing are planned for a later phase.
